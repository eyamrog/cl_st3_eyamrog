A simulation run is initialized by setting the model parameters
(see Table 1 ). Thereupon, we simulate the social network
dynamics in a disease free population until a pairwise stable
network ( Jackson and Wolinsky, 1996 ) emerges. That is
a notion of equilibrium where no agent benefits from unilaterally
breaking an existing tie and no pair of agents benefits
from jointly creating a non-existing tie. This ensures that changes
in network structure at the onset of an epidemic depend
solely on the presence of an infectious disease. If this
initialization phase did not lead to a pairwise stable and
connected network within 50 time steps , we restarted the
initialization until we had over 80,000 networks suitable for the
next phase (80,305 to be precise). Table 1 . State
