Each circle corresponds to a parameter estimate from the regression
model, with 95% confidence intervals extending out from each one.
Because all variables are scored to range from 0 to
1, parameter estimates can be interpreted as the percentage point
change in vaccination intention, compared to an omitted reference group
(denoted in the left-hand side of the Figure). Recognizing that
percentage point changes do not provide a sense of baseline
vaccination intention, however, I supplement these analyses by transforming parameter
estimates into linear predictions (expressed as likelihood ratings), holding all
