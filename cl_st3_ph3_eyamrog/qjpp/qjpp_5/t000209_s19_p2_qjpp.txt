All four archaeological samples from Liang Bua tested positive for
ancient DNA belonging to Cercopithecidae and yielded direct AMS radiocarbon
ages ( Table 1 ); however, only three of these
samples had DNA preservation suitable for subsequent sequencing of mitochondrial
genomes (see SOM and Table S2 ). The resulting three
genome sequences belong to M. fascicularis . The AMS radiocarbon
ages were calibrated using the CALIB 7.1 program ( http://calib.org
) with the offset for the Southern Hemisphere (SHCal13; Holt
et al., 2013 ) and converted into a median probability
age estimate with conventional calendar-year age ranges using 95% confidence
intervals (CIs) ( Table 1 ; Stuiver et al., 2020
). Hereafter, we refer only to the calibrated 14 C
ages and their 95% CI ranges. Because the 14 C
ages for these archaeological M. fascicularis samples were all within
the past 2,500 years, these ages were not used as
tip dates in the BEAST analysis. Table 1 . 14
