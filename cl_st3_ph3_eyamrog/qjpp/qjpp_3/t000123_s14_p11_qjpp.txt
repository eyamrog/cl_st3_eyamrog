The program SOAPdenovo v2.04.4 ( Luo et al., 2012 57.
Luo, R. ∙ Liu, B. ∙ Xie, Y. ... SOAPdenovo2:
an empirically improved memory-efficient short-read de novo assembler GigaScience. 2012;
1 :18 Crossref Scopus (3089) PubMed Google Scholar ) was
used for de novo assembly of qualified reads in three
main steps. First, the short-insert size library data were split
into appropriate K-mer sizes to construct a de Bruijn graph.
The graph was simplified by removing the tips, merged bubbles,
connections with low coverage and all of the small repeats.
Then, all qualified data were connected into contig sequences. Second,
all of the usable reads were realigned onto the contig
sequences to calculate the amount of shared paired-end relationships between
each pair of contigs, and to weigh the rate of
consistent and conflicting paired-ends before further constructing the scaffolds from
the short-insert paired ends with the long-insert paired ends. Last,
we used the GapCloser module in SOAPdenovo ( Luo et
al., 2012 57. Luo, R. ∙ Liu, B. ∙ Xie,
Y. ... SOAPdenovo2: an empirically improved memory-efficient short-read de novo
assembler GigaScience. 2012; 1 :18 Crossref Scopus (3089) PubMed Google
Scholar ) to search through the read pairs and to
identify those for which one end was mapped to the
unique contig and the other was in the gap region
based on the paired-end information. The gaps were then closed
by the local assembly for these collected reads. The program
SSPACE v2.0104 ( Boetzer et al., 2011 12. Boetzer, M.
∙ Henkel, C.V. ∙ Jansen, H.J. ... Scaffolding pre-assembled contigs
using SSPACE Bioinformatics. 2011; 27 :578-579 Crossref Scopus (1589) PubMed
Google Scholar ) was further applied to extend the pre-assembled
scaffolds using reads from all of the long-insert (2 ∼
20 kb) libraries with the following parameters: -x 0 -k
5 -n 20. The final size of the assembled genome
was 3.4 Gb (scaffold N50 = 17.8 Mb and contig
N50 = 10.2 kb). We performed a core eukaryotic gene
mapping analysis (CEGMA) ( Parra et al., 2007 77. Parra,
G. ∙ Bradnam, K. ∙ Korf, I. CEGMA: a pipeline
to accurately annotate core genes in eukaryotic genomes Bioinformatics. 2007;
23 :1061-1067 Crossref Scopus (1377) PubMed Google Scholar ) to
evaluate the quality of the monito del monte genome assembly.
Overall, 236 of 248 (95.16%) complete core eukaryotic genes were
identified.
